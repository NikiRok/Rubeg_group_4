# Рубеж — совместный проект группы 4

Единое хранилище Obsidian для аудита ИБ, доступов, сети, мониторинга и восстановления.

## Открытие
1. Склонируйте репозиторий GitHub или скачайте ZIP.
2. В Obsidian выберите «Открыть папку как хранилище» и укажите корень репозитория.
3. Откройте [[00 Главная]] и [[09 Доступы и сеть/00 Старт]].

## Совместная работа
- Каждому участнику — отдельная ветка `feature/имя-темы`, изменения через Pull Request.
- Перед началом работы: `git pull`. После изменений: `git add .`, `git commit -m "..."`, `git push`.
- Не загружайте реальные пароли, токены, ключи, персональные данные, конфиденциальные логи и дампы.
- Факты учебной игры отделяйте от целевых предложений и результатов проверки.
- Не редактируйте одновременно один и тот же Markdown-файл без согласования.

## Разделы
- `01 Контекст` — активы и условия игры.
- `02 Аудит` — замечания и проверки.
- `03 Мониторинг` — Т1/Т2, сбор событий и SIEM.
- `04 Мероприятия` — меры защиты, бюджет и восстановление.
- `05 Управление` — согласования и протоколы.
- `06 Право` — нормативные основания.
- `07 Шаблоны` — шаблоны записей.
- `08 Материалы` — исходные материалы.
- `09 Доступы и сеть` — RBAC, VPN, МЭ, IP-телефония и матрица наблюдаемости.
