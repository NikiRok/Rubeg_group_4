**Нельзя считать типовые порты доказательством:** сверить фактическую конфигурацию и зависимости. Проверить IPv4 и IPv6, обратные потоки, DNS/NTP/DHCP, правила NAT и исключения. Stateful МЭ не требует зеркальных разрешений для ответного трафика при корректном отслеживании соединений.

## Неуточнённые зависимости

- **F05:** назначенный хост подрядчика не обязательно является jump host. Тип узла, маршрут и условия допуска согласовать с группами 2 и 3 до внедрения.
- **F12:** источник потока — сервис резервирования, который может быть развёрнут на A1/A2 или отдельно. Не утверждать прямой поток A1/A2→A5 без инвентаризации.
- **F06, F07, F15:** административные соединения: АРМ→jump host; jump host→управляемые серверы; ADMIN/jump→управление IP-АТС. Общий ADMIN→MGMT без отдельного F-ID требует согласования: не считать его разрешённым автоматически.

## Правило единой нумерации

Идентификаторы F01–F16 уникальны для **сетевых потоков**. Основной реестр — эта матрица. Для обозначения правил обнаружения используются отдельные коды DET-01…DET-07 и D01…D11 (после согласования D11); они не являются ID сетевых потоков. Ранее опубликованные номера из таблицы в разделе [[17 Контроль доступа на сетевом уровне]] следует читать по обновлённым идентификаторам этой матрицы.
