**Нельзя считать типовые порты доказательством:** сверить фактическую конфигурацию и зависимости. Проверить IPv4 и IPv6, обратные потоки, DNS/NTP/DHCP, правила NAT и исключения. Stateful МЭ не требует зеркальных разрешений для ответного трафика при корректном отслеживании соединений.

## Правило единой нумерации

Идентификаторы F01–F17 уникальны для **сетевых потоков**. Основной реестр — эта матрица. Для обозначения правил обнаружения используются отдельные коды DET-01…DET-07 и D01…D10; они не являются ID сетевых потоков. Ранее опубликованные номера из таблицы в разделе [[17 Контроль доступа на сетевом уровне]] следует читать по обновлённым идентификаторам этой матрицы.
