# IP-телефония: устройство, доступы и аудит
## Компоненты
IP-телефон/softphone → голосовой VLAN → IP-АТС (PBX) → SIP-транк оператора. SIP управляет регистрацией и вызовом, RTP/SRTP передаёт голос. Медиапоток может идти напрямую между конечными устройствами, поэтому маршруты уточняются у администратора АТС.

## Матрица ролей телефонии
| Роль | Регистрация | Звонки | Запись/прослушивание | Управление АТС | Журналы CDR |
|---|---|---|---|---|---|
| Сотрудник | Свой номер | По утверждённому плану | Нет по умолчанию | Нет | Только собственная история при наличии основания |
| Руководитель | Свой номер | По плану | Только при отдельном законном основании | Нет | По регламенту |
| Администратор АТС | Сервисная роль | Тестовые вызовы | Не автоматически | По назначению | Технический доступ |
| SOC | Нет | Нет | Нет | Нет | Метаданные событий, по полномочиям |
| Подрядчик | Только согласованный тестовый номер | Ограниченно | Нет | Временный доступ по заявке | Только необходимые техлоги |

## Сетевые контроли
- [ ] Голосовой VLAN изолирован от A1, A5 и админ VLAN.
- [ ] DHCP/DNS/NTP и provisioning разрешены только к необходимым серверам.
- [ ] SIP TLS (часто TCP 5061) и SRTP по возможности; фактические порты — из конфигурации.
- [ ] Секреты регистрации уникальны, удалённый доступ к АТС ограничен.
- [ ] Установлены лимиты направлений, международных/платных вызовов и защита от toll fraud.
- [ ] Сигнализация и медиа проходят по ожидаемым маршрутам; нет прямого интернета у телефонов без необходимости.
- [ ] Проверены настройки QoS и доступность телефонии при изменениях МЭ.

## Наблюдение
SIP auth failures, необычные регистрации, смена IP устройства, массовые исходящие вызовы, изменения маршрутизации, перезапуск АТС, изменение учётных записей, недоступность SIP-транка. Содержание разговоров не собирать в SIEM без отдельного законного основания.

## Проверка
Провести тестовый внутренний/внешний звонок, регистрацию, неуспешную аутентификацию в согласованном тестовом окружении, отрицательный тест доступа к архиву; зафиксировать дату, результат, лог и ответственного.
