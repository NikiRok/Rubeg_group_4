# Аудит межсетевого экрана и VPN
## Известный факт
После обслуживания оставлено временное избыточное правило между пользовательским и административным сегментами. **Неизвестно:** номер правила, адреса, порты, назначение и журнал срабатываний.

## Порядок проверки
- [ ] Получить конфигурацию МЭ только на чтение и её контрольную сумму.
- [ ] Выделить временные/широкие правила (`any`, широкие подсети, ненужные сервисы).
- [ ] Проверить владельца, заявку, срок действия и счётчики попаданий.
- [ ] Сверить потоки с матрицей F01–F12 и реальными зависимостями.
- [ ] Согласовать узкие правила, тесты и окно изменения.
- [ ] Сохранить конфигурацию, внести изменение, провести положительные/отрицательные тесты.
- [ ] Подтвердить журналирование блокировок в Т1/A4.
- [ ] Проверить NAT, IPv6, правила в обе стороны и альтернативные пути обхода.

## VPN
- [ ] Именные учётные записи, MFA, профиль по роли.
- [ ] Разделение подрядчиков, сотрудников, администраторов.
- [ ] Ограничения времени и сроков действия.
- [ ] Логи: вход, отказ, MFA, исходный IP, назначенный профиль, изменение настроек.
- [ ] Нет доступа из VPN в административный VLAN без выделенной процедуры.

## Откат
Откат не должен безусловно возвращать заведомо опасное широкое разрешение. При отказе бизнес-функции согласовать временное минимальное исключение, срок, журналирование и ответственное лицо.
