# Привилегированный доступ
## Разделить административные области
- Сеть/МЭ/VPN — сетевые администраторы.
- ОС и серверы — системные администраторы.
- Портал и БД — администраторы приложений/БД.
- IP-АТС — администраторы телефонии.
- A4/SIEM — администраторы мониторинга; аналитики — преимущественно read-only.
- A5 — оператор восстановления и отдельный хранитель ключей.

## Контроль
- [ ] Именные админ-аккаунты, отдельные от повседневных.
- [ ] MFA и доступ через контролируемый jump host.
- [ ] Временная выдача прав (JIT) при технической возможности.
- [ ] Запрет прямого входа с пользовательского VLAN.
- [ ] Регистрация выдачи прав, команд/сессий по утверждённому регламенту.
- [ ] Контроль аварийной учётной записи: опечатанный секрет, двойной контроль, последующий разбор.
- [ ] EDR на 5 из 5 критичных АРМ; на момент вводной — только 3 из 5.

Проверить, что администратор ОС не получает автоматически права на бизнес-операции с материалами A1/A2.
